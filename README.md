# XP Scale

XP Scale is a Minecraft texture pack that dynamically scales the player's skin based on their XP gain. This pack allows players to customize their experience by choosing whether their skin should grow or shrink as they gain XP. The scaling effect is smooth and designed to minimize lag, ensuring a seamless gameplay experience.

## Install

1. Download the XP Scale texture pack from the GitHub repository.
2. Open Minecraft.
3. Navigate to the "Options" menu.
4. Select "Resource Packs" and click "Open Resource Pack Folder."
5. Copy the downloaded XP Scale folder into the resource pack folder.
6. Go back to the "Resource Packs" menu in Minecraft and enable the XP Scale texture pack.
7. Ensure that the XP Scale pack is at the top of the list to override other packs if necessary.

## Use

1. Start a new world or join an existing one.
2. Play the game as usual.
3. As you gain XP, observe your skin scaling up or down based on the configuration settings.
4. Customize the scaling behavior by editing the configuration file in the texture pack folder.
